# Cross-task prompt repair data (working area)

This directory holds planning and provenance for the new multi-task project.
The original frozen college-notice study remains separate and unchanged.

Raw public-dataset samples are not included in the restart ZIP. They remain in
the Molab working runtime; the source manifests record IDs, splits, hashes, and
license notes. Only training splits may be used to create repair examples.
Held-out splits are reserved for evaluation after prompt/model choices are
frozen.
